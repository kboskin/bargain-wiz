# Instagram creator search — Bargain Wiz UGC

Queries and hashtags for finding UGC creators on Instagram (Reels + hashtag pages) in the two
niches chosen on 2026-09-22: **wave 1** Facebook Marketplace lowball / haggle, **wave 2**
furniture and side-hustle flippers. Generic niches (frugal living, car buying, thrift fashion)
are listed at the bottom only as "skip / later".

How to use:
1. Search each hashtag on Instagram, switch to **Reels**, sort by recent, note creators in the
   5K–80K follower range who show marketplace chats or deals on screen.
2. Paste a hashtag *group* into a Reel caption search or the Explore search bar; Instagram
   matches partial phrases, so plain-text queries work too.
3. Fill the `Posts` column from the hashtag page header when you look, so we can drop dead tags.
4. Log candidates in `creator_shortlist.csv` next to this file.

Legend: **T1** = core, search first · **T2** = adjacent, search second · **T3** = broad,
only for volume.
