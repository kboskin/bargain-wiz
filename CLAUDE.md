# Bargain Wiz

Two halves in one git repo (root = this folder): `wizard-app/`, a Flutter client for iOS
and Android, and `wizard-backend/`, a Firebase project of Python 3.12 Cloud Functions backed by
Firestore, Cloud Storage and Gemini on Vertex AI.

Everything an agent needs — tech stack, how the halves talk, working agreements, skills and the
current environment blockers — lives in AGENTS.md, imported below. Each half has its own
`AGENTS.md`; read the one for the code you are touching.
